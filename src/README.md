# 🛍️ Mini E-commerce Project

## 📌 Overview
This is a **mini e-commerce web application** built with **React + TypeScript + Vite**.  
It allows users to:
- View products with image, description, price, colors, and category.
- Add new products dynamically.
- Edit existing products.
- Remove products.
- Get instant feedback with toast notifications.

---

## 🚀 Tech Stack
- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **react-hot-toast**
